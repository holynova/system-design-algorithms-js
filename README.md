# 系统设计经典算法全景图解 (System Design Algorithms in JS)

基于 Alex Xu 经典著作《System Design Interview: An Insider's Guide》（系统设计面试：内幕指南）第一卷与第二卷的全部 **28 个章节**，使用现代 JavaScript (Node.js 原生 ES Modules) 完整实现核心经典算法与数据结构，附带交互式可视化 Web 门户。

## ⚡️ 快速上手 (Quick Start)

本项目**零外部 npm 依赖**，基于 Node.js 原生模块运行：

```bash
# 1. 运行全量 58 项自动化单元测试 (100% 通过)
npm test

# 2. 启动本地交互式可视化 Web 门户 (浏览器打开 http://localhost:3000)
npm run web

# 3. 运行全算法终端控制台 Demo 演示
npm run demo
```

> 📖 查看全部 28 章算法详细索引与架构设计请参阅 [CATALOG.md](./CATALOG.md)。
